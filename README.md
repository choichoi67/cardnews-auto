# Cardnews Auto

RSS 뉴스를 모아 AI가 주제를 선정하고, 카드뉴스 원고·캡션을 만든 뒤 템플릿 제작에서 확정한 디자인으로 JPG를 생성하여 Google Drive로 올리는 자동화입니다. Photoshop은 필요하지 않습니다.

## 운영 웹 대시보드

`dashboard.cmd`를 더블클릭하면 브라우저에서 **Cardnews Control Room**이 열립니다.

대시보드에서는 다음 작업을 할 수 있습니다.

- 외국 힙합, 패션, 스포츠 등 여러 매거진 프로필 생성·전환
- 매거진별 카테고리, 뉴스 사이트/RSS, 브랜드 톤 설정
- 템플릿 제작: PSD를 한 번 불러와 편집하고, 표지·본문·CTA 버전을 채널에 적용
- 카드 장수 자동 결정 또는 채널별 고정 장수 설정(6장 제한 없음)
- 채널별 1회 수집 기사 수와 하루 1~10회 예약 시각 설정
- 뉴스 수집과 Telegram 승인 요청 실행
- 후보 기사 한국어 요약 확인 및 웹 승인
- 승인된 주제의 카드뉴스 제작
- 실행 상태, 실패 로그, 최근 산출물 미리보기
- Google Drive OAuth가 연결된 경우 제작 후 자동 업로드
- Drive 업로드 완료 즉시 Telegram으로 카드뉴스 앨범·Drive 링크·캡션 전송

로컬 운영 도구입니다. 제작 작업은 공용 대기열에서 최대 2건씩 동시에 처리하고, 한 건 안의 카드도 동시에 출력합니다.

템플릿은 대시보드의 **템플릿 제작**에서 관리합니다. PSD를 불러오면 원본을 `templates/originals`에 한 번만 보관하고, 레이어·글꼴을 편집 가능한 초안으로 바꿉니다. 초안을 확정하면 바뀌지 않는 버전이 만들어지고 채널의 표지·본문·CTA에 적용됩니다. 결과물은 그 버전을 하드링크로 가리켜 다시 복사하지 않습니다. 배지 상자·글자 색은 편집 화면의 색상 선택칸(RGB)으로 고릅니다. 템플릿에 쓰인 글꼴은 Windows 글꼴 폴더와 `templates/fonts`에서 찾습니다.

예약 수집은 대시보드가 실행 중일 때 동작합니다. 각 채널 설정에서 `예약 수집 사용`을 켜고 하루 실행 횟수와 시각을 저장하면, 같은 날짜·같은 시각에는 한 번만 수집합니다. 예약 수집 후 Telegram 후보 알림까지 기존 채널 설정대로 이어집니다.

Telegram 앨범은 한 묶음당 최대 10장인 플랫폼 규칙에 맞춰 자동 분할하며, 전체 카드가 빠짐없이 전송됩니다.

Drive 산출물은 기본적으로 아래 구조에 저장됩니다.

```text
Cardnews Auto / 연도 / 월 / YYYY-MM-DD / 매거진 / HHMM_주제
```

같은 날짜 폴더와 매거진 폴더는 재사용하고 제작 건만 시간·주제별로 분리합니다. `credentials.json`으로 처음 OAuth를 연결할 때 반드시 산출물을 저장할 Google 계정으로 로그인하세요.

## 자동화 흐름

1. `config.yaml`의 RSS에서 최근 뉴스 수집
2. AI가 시의성·독자 효용·신뢰성을 기준으로 주제 선정
3. 슬라이드 원고와 Instagram 캡션/해시태그 생성
4. 승인된 기사의 표지 사진을 GPT Image로 고해상도 편집
5. 채널의 템플릿 버전에 글자·사진을 넣어 JPG 출력 (글자 넘침·겹침 검사 포함)
6. 결과물, 캡션, JSON 원본을 Google Drive에 업로드

## 처음 설정

1. `config.example.yaml`을 `config.yaml`로 복사합니다. 채널 설정(`config.yaml`, `magazines/`)과 템플릿 데이터(`templates/originals`, `templates/channels`)는 깃에 올리지 않고 운영 PC에만 둡니다.
2. 템플릿 제작에서 채널의 표지·본문 버전을 적용합니다.
3. `.env.example`을 `.env`로 복사하고 OpenAI API 키를 입력합니다.
4. `config.yaml`에서 카테고리, RSS, 브랜드 톤을 수정합니다.
5. Drive API 데스크톱 OAuth 자격 증명 `credentials.json`을 넣고 `drive.enabled: true`로 바꿉니다.

## 승인 기반 실행

1. RSS 후보를 수집합니다. 이 단계에서는 OpenAI 호출이나 제작을 하지 않습니다.

```powershell
.\review.cmd collect
```

후보 목록은 터미널과 `state/review.md`에 저장됩니다. 다시 보려면:

```powershell
.\review.cmd list
```

2. 카드뉴스로 만들 후보 번호를 승인합니다.

```powershell
.\review.cmd approve 3
```

3. 승인된 주제만 제작합니다.

```powershell
.\review.cmd build -NoUpload
```

템플릿 없이 기본 레이아웃으로 흐름만 시험하려면 `-Preview`도 붙입니다. Drive 첫 업로드 때 브라우저 OAuth 승인이 한 번 필요합니다.

```powershell
.\review.cmd build -Preview -NoUpload
```

## 카드 출력 방식

- 글자 배치·효과는 PhotoCraft(github.com/storytold/photocraft, MIT/Apache-2.0)의 규칙을 Python으로 옮겼습니다. 기준점·글상자 배치, 가로 비율, 자간, 두 가지 색 스타일, 그림자(텐트 번짐), 외곽선을 재현합니다.
- 글자 크기는 줄이지 않습니다. 긴 문구는 줄바꿈 규칙과 글자 수 제한으로 정리하고, 허용 영역을 넘거나 다른 글과 겹치면 제작을 멈춥니다.
- 배지 상자는 글자 길이에 맞춰 폭이 바뀌고, 글자는 상자 가운데에 놓입니다. 배지 문구가 없으면 상자도 숨깁니다.
- 표지 칸의 "AI가 기사마다 배지 색 변경" 스위치를 켜면 원고 AI가 기사의 중심 팀·인물 색을 골라 배지 상자를 칠하고, 배지 글자는 읽기 쉬운 흰색·검정으로 바뀝니다. 끄면 템플릿에서 RGB로 고른 색을 씁니다. 색을 확신하지 못하면 템플릿 색으로 돌아갑니다. 풋매코는 켜져 있습니다.
- CTA 버전을 적용하면 마지막 장에 고정 디자인으로 붙습니다.
- 오래된 이미지 캐시는 제작할 때마다 14일 기준으로 지웁니다. 한 번에 정리하려면 `clean.cmd`를 실행합니다.

## 표지 이미지 편집

- `config.yaml`의 `image_transform`에서 모델, 품질, 출력 크기, 편집 프롬프트를 관리합니다.
- 이미지 편집은 RSS 수집 단계가 아니라 승인 후 제작 단계에서만 실행됩니다.
- 같은 원본과 프롬프트는 캐시를 재사용해 중복 API 비용을 막습니다.
- 원본에 팔과 손이 보이지 않으면 크롭을 바꾸지 않도록 프롬프트가 포즈 변경보다 원본 보존을 우선합니다.
- AI 편집은 원본 사진의 저작권이나 라이선스를 없애지 않습니다. 게시 전 사용 권한과 출처를 확인하세요.

## Telegram 휴대폰 승인

1. Telegram의 `@BotFather`에서 봇을 만들고 새 토큰을 발급받습니다.
2. `telegram-setup.cmd`를 실행하고 토큰을 입력합니다. 봇 검증, `/start` 감지, `.env` 저장이 자동으로 진행됩니다.
3. 대시보드를 실행하면 Telegram 승인 수신기도 함께 시작됩니다.

이후 `review.cmd collect`를 실행하면 휴대폰으로 상위 후보 10건과 승인 버튼이 전송됩니다. 최초 승인 한 건만 기록하고 제작을 시작합니다. PC에서 Telegram 수신기가 실행 중이어야 버튼 응답이 처리됩니다.

> 채팅이나 이미지에 노출한 기존 토큰은 `@BotFather`의 `/revoke`로 폐기하고 새 토큰을 사용하세요.


### 사진이 부족하거나 편집에 실패한 경우
웹 사진 후보를 추가 검색하고 실제 이미지 중복·발행 규격을 검사합니다.
`image_transform.recompose_for_publication: true`이면 규격이 맞는 원본도 포함해 모든 선택 사진을 AI 워싱합니다.
원본 인물·실제 장면을 보존하며 선명도·질감을 개선하고 보이는 팔·손만 미세 조정해 3:4로 재구성합니다.
기사 제목·카드 본문·검색어·확보된 사진 설명은 장면 창작 지시가 아닌 참고 문맥으로 전달합니다.
현재 모델은 `grok-imagine-image-2.0`이며 `.env`의 `XAI_API_KEY`를 사용합니다. 생성·편집 모두 3:4, 2k, medium 품질로 요청합니다.
사진 후보가 없거나 편집 실패 뒤 유효한 원본도 없으면 같은 모델로 인물 없는 설명 일러스트를 생성합니다.
안전 차단된 원본·편집 지시는 재전송하지 않습니다. 설명 일러스트는 실제 사건 사진으로 표시하지 않고 캡션에 구분합니다.
생성 결과와 캐시는 3:4·1080×1440 이상을 허용하고 최종 1080×1440으로 비례 축소합니다.
생성까지 실패하거나 최종 이미지가 중복이면 원인을 안내합니다. 재시도 작업도 현재 이미지 모델 설정을 적용합니다.

### Telegram 작업 비용·시간

제작 진행 메시지에 API 작업별 USD 비용, 호출 시간과 게시물 합계를 표시합니다.
과거 작업의 비용 기록은 보존합니다.
OpenAI는 2026-10-13 확인한 표준 단가와 응답 사용량으로 추정하며 웹 검색 도구 비용도 포함합니다.
알 수 없는 모델·사용량 없는 오류는 0달러가 아니라 확인 불가로 표시합니다.
캐시 재사용은 해당 작업의 추가 API 비용 0달러입니다. 구독료·세금은 제외합니다.
SDK 내부 네트워크 재시도의 개별 청구액은 응답만으로 완전히 복원할 수 없습니다.
state/job_usage/<작업ID>.json에 상세 내역이 저장됩니다. API 키나 프롬프트·응답 본문은 저장하지 않습니다.
총 실행 시간은 대기열을 제외한 실제 경과 시간이며, 병렬 API 호출 시간 합계와는 다릅니다.
대시보드 재시도는 기록이 있는 이전 시도 비용을 누적합니다. 새 제작 버튼으로 별도 시작한 작업 및 기능 적용 전 비용은 자동 복원하지 않습니다.
단가는 usage_meter.py에서 관리하며 가격 변경 시 갱신해야 합니다.


### 카드별 원고·사진 배치 (2026-10-13)
- 신규 제작은 표지 제목과 PSD에 매핑된 배지·작은 보조 문구를 표시합니다. 본문은 제목 없이 완결된 내용 2~3줄이며 풋매코의 2줄 PSD 제한을 유지합니다. 마지막 장도 뉴스 본문과 해당 내용의 이미지를 표시합니다. 신규 제작에는 고정 CTA를 붙이지 않습니다.
- 원고가 넘치면 다시 편집하며, 문장을 자르고 제목·검색어를 복사해 카드를 늘리지 않습니다. 중복 본문·미완성 문장도 재편집 대상입니다.
- 본문이 2장 이상이면 이미지 검색 전 AI가 전체 카드의 검색어를 한 번에 비교·재구성합니다. 동의어 교체 대신 기사에 근거한 인물·장소·대상·촬영 장면을 나누며, 기사 문장은 바꾸지 않습니다. 원래 검색어·새 검색어·사진 선택 의도를 이미지 검색 기록에 남깁니다. 이 호출은 `이미지 검색어 재구성` 비용으로 집계됩니다.
- 본문별 검색어를 작성하고, 비었거나 반복된 검색어는 해당 본문에서 복원합니다. 모든 본문에 별도 검색 기회를 배정하므로 종전 기사당 검색 제한보다 호출 수가 늘 수 있습니다. 사용량 알림에 반영됩니다.
- 웹 검색 → 추가 후보 검색과 실제 이미지 중복 검사를 유지합니다. 사진 확보에 실패하면 위 설명 이미지 생성 절차를 사용하며 빈 배경으로 정상 완료 처리하지 않습니다.
- 예전 결과물은 자동 변경하지 않습니다. 새 형식은 신규 제작 또는 전체 재제작부터 적용합니다.


## 채널 템플릿과 공통 이미지 정책 (2026-10-18)

- `image-policy.yaml`이 전 채널 이미지 검색·편집 설정의 기준입니다. 채널 설정에 남은 이미지 모델/프롬프트는 실행 시 공통 정책으로 대체합니다.
- 채널 템플릿은 템플릿 제작의 활성 버전(`templates/channels/<채널>/active.json`)입니다. 원고 작성 전에 버전을 확정하고, 버전 파일의 해시가 바뀌면 제작을 멈춥니다.
- 2026-10-18 외힙·풋매코의 기존 Photoshop 표지·본문을 같은 레이어 매핑·허용 영역으로 템플릿 버전으로 전환했습니다.
- Photoshop으로 만든 예전 결과물은 카드 한 장 수정 대신 전체 재제작을 사용합니다.
