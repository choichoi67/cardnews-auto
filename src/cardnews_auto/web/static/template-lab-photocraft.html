템플릿 편집 안내

레이어 선택 → 속성 편집 → 초안 저장 → 채널에 적용 순서로 작업하세요.

  • 레이어 목록을 드래그해 앞뒤 순서를 바꿉니다.
  • 캔버스에서 선택 테두리를 드래그해 이동하고 모서리로 크기를 조절합니다.
  • 캔버스에 초점이 있을 때 방향키로 1px, Shift와 함께 10px 이동합니다.
  • Ctrl+Z / Ctrl+Shift+Z는 캔버스에서 실행 취소 / 다시 실행입니다.
  • 브러시·마스크·선택 영역 도구는 현재 연결된 기능에 포함되지 않습니다.
